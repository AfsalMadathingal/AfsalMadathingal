# Hi, I'm Afsal 👋

I'm a full-time Software Engineer who likes building things end to end: frontend, backend, infrastructure, and the deployment pipeline that ties it all together. I've worked across MERN and Next.js apps, cloud infrastructure with Terraform, desktop apps with Electron, and web scraping pipelines, always with an eye on what actually needs to run in production, not just work on my machine.

Lately I'm spending most of my time on agentic AI. I build with Claude and MCP (Model Context Protocol), and I'm exploring how far autonomous agents can go in real workflows like customer support, ranging from tool design to keeping agents safe and predictable when they're acting on live systems.
